Introduction to Networking
Overview
This repository documents my learning journey in computer networking, focusing on the fundamental concepts required for cybersecurity and penetration testing.

Learning Objectives
Understand what computer networking is and how it works.
Learn the OSI and TCP/IP models.
Understand IP addresses and subnetting.
Learn about TCP, UDP, and common network ports.
Understand DNS, HTTP, and HTTPS.
Explore routing, switching, and network devices.
Practice using networking tools.

To build a strong networking foundation for ethical hacking, vulnerability assessment, and penetration testing.
